# Monetization Playbook - Aegis-Air

This is a commercial planning artifact, not a revenue guarantee. It exists to turn an archived technical proof into a clear, ethical selling motion.

## Commercial Lane

- **Lane:** Air-gapped incident review and RCA proof
- **Primary buyer:** Regulated SRE, security operations, platform reliability, and systems integrator teams.
- **Why this can sell:** Teams with strict telemetry boundaries still need structured incident evidence and replay-backed RCA.

## Offer Ladder

1. **Trust-boundary diagnostic** - $5k-$15k. Map incident data movement, local model posture, and evidence gaps.
2. **Restricted-environment pilot** - $30k-$90k. Adapt the replay suite and RCA taxonomy to one production-like service.
3. **Local incident review license** - $120k+/year. Package the runtime, replay harness, and operator review workflow for internal use.

## Acquisition Channels

- Regulated reliability engineering content
- Security and platform partner referrals
- Comparison page against cloud-connected incident tools

## Proof Gates Before Selling

- Replay suite remains runnable
- Trust boundary is visible in README and API surfaces
- AegisOps relationship is clearly explained

## Risk Boundaries

- Do not claim live telemetry access in the public demo
- Keep local-first boundaries explicit
- Frame as supporting proof, not the active flagship

## 30/60/90 Day GTM

- **30 days:** Publish a one-page restricted-ops diagnostic
- **60 days:** Build a sample regulated incident replay pack
- **90 days:** Offer a narrow RCA pilot to security-conscious teams

## Metrics That Matter

- Diagnostic requests
- Pilot conversion
- Replay coverage
- Time-to-RCA delta

## Positioning Note

Keep the repository's archived status visible. Sell the reusable workflow, diagnostic, enablement material, or pilot path that the proof makes credible; do not sell the archive as an unsupported production service.
